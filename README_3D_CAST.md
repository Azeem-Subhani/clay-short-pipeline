# The 3D cast: what this zip is and how to install it

This replaces the flat 2D character pack with 3D figures for the standard cast. Unzip it over the project folder
(`clay-short-pipeline/`); it adds and overwrites the files listed at the end. No `.blend` library is involved: a
character is a sheet in a JSON file, built when a shot runs.

## What you get

- **92 standard characters as real models**: round body, painted face with expressive eyes, sculpted hair and beards,
  clothes and hats with thickness and material, no outline. The camera can go anywhere round them. Lineups: `docs/lineup_3d_front.png`, `docs/lineup_3d_3q.png`,
  `docs/lineup_3d_back.png`.
- **Generated hair and beards.** 49 characters wear a hairstyle and 16 a beard or moustache from the model library in
  `library/hair/` (25 hairstyles, 7 facial pieces, made from image-to-3D models). Who wears what is one list,
  `config/cast3d_generated.json`. Characters in hats, helmets, caps and hoods keep sculpted hair. See "Generated hair"
  in `docs/CHARACTERS_3D.md`.
- **The same commands as before.** `cast.actor`, `cast.from_plan`, poses, `reach`, `hold`, `walk`, `expr`, `speak`,
  the plan's `costume` dict and all 118 named actions (`actor.do(...)`) work on them without changes to shot files.
- **The wardrobe**, all 17 pieces, on the 3D figures: `docs/wardrobe_3d.png`.
- **New characters in a few lines**: a sheet in `config/cast3d_custom.json` that says which character it is like and
  what differs. Two worked examples are in that file (`TownGuard`, `Beekeeper`); their pictures are
  `docs/new_character_example_*.png`.
- **The guide**: `docs/CHARACTERS_3D.md` (using a character, dressing it, custom clothing, making a new one, limits).
  The `character-maker` skill is the short form for agents.

## How the pipeline should use it

1. **Cast from the lineup.** `python tools/clip.py cast --era <era>` lists who fits; `cast <Name>` shows colours,
   parts, stand-ins and whether the figure is 3D.
2. **Re-costume in the plan** when the role is an existing body in other clothes (`recolor`, `hide`, `wear`).
3. **Make a new sheet** when a script has a character the lineup lacks (`character-maker` skill). Look at it with
   `tools/chars3d/look3d.py`, test it with `tools/chars3d/action_test3d.py`, register it in `config/cast.json`.
4. **Move the camera freely.** Arcs and full circles round a 3D figure are ordinary `cam.move(...)` steps.

## What is not in it

Thirteen special bodies were left out on purpose: Ghost, Mermaid, Dragon, Fairy, Robot, Alien, Werewolf, Mummy, Genie,
Goblin, Monster, Devil, Skeleton. A plan that casts one still gets the old flat character, which needs the 2D pack in
`packs/` and a camera that stays in front of it. Decide per story whether to build that body in 3D first.

To go back to the flat cast for everything, put `CAST_STYLE=2d` in `.env`.

## Tested

- The four shot files of the example clip build unedited with the 3D cast.
- All 118 actions on all 92 characters, measured on every frame: `docs/ACTIONS_3D_RESULTS.md`.
- Known limits are listed at the end of `docs/CHARACTERS_3D.md`.

## Files

| File | New or changed | What |
|---|---|---|
| `tools/blender/stagekit/fig3d.py` | new | builds one 3D figure from a sheet |
| `tools/blender/stagekit/cast3d.py` | new | the 3D actor: the same commands as the 2D actor |
| `config/cast3d.json` | new | the 92 sheets converted from the 2D pack (regenerated by `tools/chars3d/convert_pack.py`; do not edit) |
| `config/cast3d_custom.json` | new | characters made in this project: add yours here |
| `tools/chars3d/*.py` | new | look3d, lineup3d, action_test3d, run_actions, make_results, convert_pack, dump_pack |
| `docs/CHARACTERS_3D.md`, `docs/ACTIONS_3D_RESULTS.md`, `docs/*.png` | new | guide, test results, lineups, wardrobe, examples |
| `tools/blender/stagekit/cast.py` | changed | `cast.actor` returns a 3D figure when the character has a sheet |
| `tools/blender/stagekit/actions.py` | changed | three places that reached into the 2D rig now ask the actor |
| `tools/blender/stagekit/wardrobe.py` | changed | one line: skips a 2D-only step for 3D figures |
| `tools/blender/stagekit/review.py` | changed | the ground check looks through a figure's own layers |
| `tools/blender/stagekit/lights.py` | changed | the light rig adds a soft back light for the cast by default (`rim=0` turns it off) |
| `tools/blender/run_shot.py` | changed | figures settle their headings once the camera is known |
| `tools/clip.py` | changed | `cast <Name>` says whether a character is 3D |
| `config/cast.json` | changed | the two example characters registered |
| `CLAUDE.md`, `.claude/skills/character-maker`, `stagekit`, `cinematic-style` | changed | instructions for agents |
