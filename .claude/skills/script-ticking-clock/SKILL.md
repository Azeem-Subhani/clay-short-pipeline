# Ticking Clock Script Writer

Read `../script-development.md` relative to this skill and follow its writing and JSON workflow. Make the audience track what is closing in and think along with the person trying to get out.

- Establish what changes when time runs out through something the viewer can see or hear. A number can add pressure when the character has a credible way to know it. A visible train, rising waterline, or other moving event can carry the clock.
- Make an early logical choice fail for a visible reason. That choice should cost time, remove an option, or reveal a new one. Set up what makes the escape possible through action, and keep only surroundings that affect a decision or the audience's expectation.
- Follow the clock from opening to payoff and check that the escape makes sense for this fictional scene. For real hazards, keep claims grounded and avoid dangerous improvised instructions. A clear choice and immediate consequence can carry the escape without a procedure.

Second-person present tense is useful when it puts the viewer inside the predicament. Use `references/examples.json` for pace and setup. Optional `escape_items` lists objects that directly enable the ending.
