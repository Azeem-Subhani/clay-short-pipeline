# Micro-Butterfly Script Writer

Read `../script-development.md` relative to this skill and follow its writing and JSON workflow. Make the connection between a tiny action and an improbable consequence irresistible to follow.

- Find a small act an ordinary person would do for a recognizable reason. Choose an outcome specific enough to picture. An invented date, emphatic adjectives, or a huge number will rarely make the contrast interesting on their own.
- Trace the chain backward. Each link needs an action and a reason it sets up the next action. When the explanation is “then this happened,” give it a genuine dependency or drop that link. Show the best discovery or choice from the middle in the scene.
- Test the counterfactual. If the first act never happened, which later event becomes impossible or substantially less likely? Cut coincidences that can do the same job alone. At the end, let an image or an ordinary action show the cost. Repeat the trigger only if hearing it in its new context lands harder.

Opening on the big consequence and then returning to the small act is a useful default. Use `references/examples.json` to study visible dependencies. Optional `trigger` and `chain` summarize the actual causal path.
