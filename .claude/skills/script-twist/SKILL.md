# Twist Script Writer

Read `../script-development.md` relative to this skill and follow its writing and JSON workflow. The viewer came to figure out how somebody pulled off the impossible.

- Open on a concrete result someone can picture. Write down the viewer's likeliest explanation, then use an actual event to make that answer doubtful. A string of narrator denials is rarely as interesting as seeing a reasonable guess fail.
- Build backward from an exact action that changes the outcome. Give the opponent a believable motive for misreading that action, and let the viewer share their assumption. Plant the evidence in action or dialogue with an innocent first meaning.
- The reveal should let the viewer retell the trick in one plain sentence using something they already saw or heard. If the result depends on a new fact introduced at the reveal, plant it or try a better premise. End on the consequence, reaction, or punchline that earns the cut.

A useful progression is impossible outcome, obvious explanation fails, odd move, opponent commits, payoff. Move or combine those turns when it helps the story. Use `references/examples.json` to study how to hide a clue in a confident mistake.
