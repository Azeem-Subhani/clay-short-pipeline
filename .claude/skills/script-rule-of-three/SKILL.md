# Rule of Three Script Writer

Read `../script-development.md` relative to this skill and follow its writing and JSON workflow. Make the viewer want to try the puzzle and enjoy each challenger even after guessing the answer.

- Give the prize a specific reason to matter and make the challenge easy to repeat after one listen. Build a solution around something demonstrated in the scene. Give that detail an ordinary role before it becomes useful.
- Give earlier attempts different smart assumptions. Each try should change the problem, teach a fact, cost something, or earn a laugh worth the time. If an attempt can swap places with the other without changing anything, make the sequence build or shorten it.
- Test the winning move against how an ordinary listener understood the rule. Show it working. If naming the setup gives the answer away immediately, bury it in a useful action or make the real surprise about what winning costs. End on a good reaction or a joke that belongs to these people.

Three tries are the default pattern. They can overlap or vary in length. Use `references/examples.json` to study fair physical and timing solutions. Optional `rule` and `loophole` describe the condition and how it is satisfied.
