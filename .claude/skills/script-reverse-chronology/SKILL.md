# Reverse Chronology Script Writer

Read `../script-development.md` relative to this skill and follow its writing and JSON workflow. Open on an image worth explaining, then make seeing it again worth the wait.

- Show an unlikely combination of action, object, and stakes, then give the audience a clear time marker when you rewind. Keep one narrative line from that point to the return unless a different order makes the cause easier to grasp.
- Give each prominent opening detail an ordinary first use in the rewind or a job at the payoff. The middle needs a consequential choice or mistaken assumption that forces the scramble. A list of events that happen to end in chaos will feel interchangeable.
- During the return, advance the action beyond the first image or reveal what the first image actually meant. Try removing the rewind. If the opening and the ending feel the same, the middle needs to change what the viewer believes about that picture.

A single rewind and second-person narration are useful starting points. Use `references/examples.json` to study what makes a prop worth revisiting. Optional `props` lists the setup objects with a payoff.
